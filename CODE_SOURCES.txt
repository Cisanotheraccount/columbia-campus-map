DATA AND STYLE
Columbia Blue style.json is reused from Ci Song's Tutorial 8.1.
Building reference coordinates and space directory records are reused from
Assignment 2's checked Manhattan dataset. Prior data preparation also used
AI assistance; this is not a new field survey or verified indoor navigation.
The derivative joins existing records by stable building_id and preserves
original coordinates. No room, floor, door, or new building coordinates created.
Source URLs remain attached to each building/space. Input hashes and workspace-relative
source paths are in sources/data-provenance.json.
Basemap services: OpenFreeMap, OpenMapTiles, OpenStreetMap contributors.
